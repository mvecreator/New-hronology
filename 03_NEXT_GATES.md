# 03. Следующие gates

## SAXO-PACKAGE-1
Проверить целиком пакет: `prediction + fixed delay + funeral/memorial + return alive + same protagonist + high centrality`. Искать международные аналоги именно всего пакета, а не отдельных мотивов. Отдельно учитывать ритуальные death/rebirth структуры и `U_survival`.

## MDL-1
Для 30–50 конкретных соответствий НХ посчитать `role_swap`, `event_substitution`, `order_break`, `metaphoric_jump`, `source_jump`, `new_rule`.

## CHRISTIAN-CONTROL-1
Расширить контроль минимум до 20 житий, 5–10 моралите и 5 открытых imitatio Christi текстов.

## MANUSCRIPT-SURVIVAL-1
Для каждого текста хранить `date_range`, `surviving_manuscripts`, `known_lost_witnesses`, `earliest_print`, `transmission_notes`, `uncertainty_grade`.

## TRUE-HOLDOUT-1
После окончательной заморозки модели заранее зарегистрировать expected patterns, провести blind scoring и только после подсчёта раскрыть класс текста, если дизайн позволит.

## RULE-SATURATION-1
После каждого нового текста считать `DeltaF_n = number of genuinely new transformation rules`. Сильная кодовая модель ожидает `DeltaF_n -> 0`.
