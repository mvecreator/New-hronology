# NH Anti-Gospel Research Foundation v0.1

Рабочий воспроизводимый пакет для проверки гипотезы Носовского–Фоменко об «анти-Евангелиях».

## Статус

Это исследовательский фундамент, а не доказательство какой-либо версии. Цель — заморозить текущие определения, данные, ограничения и тесты, чтобы дальнейшая работа не зависела от восстановления логики из чата.

## Гипотезы

- **H0** — универсальные/случайные сюжетные совпадения.
- **HB** — международные фольклорные мотивы + христианская культурная матрица / imitatio Christi / десакрализация.
- **HC** — единый исходный евангельский/христологический прототип, сознательно преобразованный в «анти-Евангелия».

## Главный текущий объект

Сильнейшим объектом оказался связный пакет Саксона:

`предсказание/план → фиксированный срок → ожидание смерти → поминальный ритуал → возвращение живым → кульминация`.

Он сильнее разовых соответствий типа `актёры = апостолы`, потому что сохраняет героя, порядок, внутреннее предсказание и высокую сюжетную центральность.

## Политика обновлений репозитория

Репозиторий обновляется **только при значимом исследовательском результате**, а не после каждого промежуточного шага.

Значимым результатом считается как минимум одно из следующего:
- пройден или провален заранее зафиксированный gate;
- существенно изменилось соотношение H0 / HB / HC;
- появилась новая воспроизводимая метрика или скрипт, меняющий вывод;
- найден новый сильный первичный источник или источниковедческий факт;
- подтверждён новый out-of-sample результат;
- обнаружена ошибка, меняющая ранее зафиксированный вывод.

Промежуточные поиски, частичные совпадения и незавершённые гипотезы остаются в рабочем чате до прохождения этого порога.
